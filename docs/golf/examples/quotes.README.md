# Golf quotes example

`quotes.txt` is generated by `scripts/scrape_golf_quotes.py`. Regeneration is
a manual development step. To use the generated collection, copy `quotes.txt`
to the SD card as `/golf/quotes.txt`.

The collection has two source tiers. Tier 1 contains quotes from English
[Wikiquote's Golf page](https://en.wikiquote.org/wiki/Golf) and subject pages
discovered through the [Golfers](https://en.wikiquote.org/wiki/Category:Golfers)
and [World Golf Hall of Fame inductees](https://en.wikiquote.org/wiki/Category:World_Golf_Hall_of_Fame_inductees)
categories. Wikiquote page text is available under the
[CC BY-SA 4.0 licence](https://creativecommons.org/licenses/by-sa/4.0/). The
generator report names every fetched Wikiquote page and its extraction count.

Tier 2 contains attributed quotes printed by these broader golf-specific
collections:

- [Golf Monthly: 32 Best Golf Quotes](https://www.golfmonthly.com/features/32-best-golf-quotes)
- [Golf Monthly: Best Masters Quotes](https://www.golfmonthly.com/tour/us-masters/masters-history-records/best-masters-quotes-177549)
- [EEE Golf: Funny Golf Quotes](https://eeegolf.com/funny-golf-quotes/)
- [Sports Feel Good Stories: Golf Quotes](https://www.sportsfeelgoodstories.com/golf-quotes/)
- [The End Quotes: Best Golf Quotes](https://theendquotes.com/best-golf-quotes/)
- [Quotlr: Golf Quotes](https://quotlr.com/quotes-about-golf/)

Tier 2 is useful for breadth but has weaker verification than Wikiquote. Its
entries carry a real, non-zero risk of misattribution. The generator rejects
unknown speakers, conflicting attributions, known disputed claims, duplicates,
and quote text longer than 110 characters; it does not fabricate or paraphrase
content. Tier metadata stays in the generator report rather than `quotes.txt`
because the device file format has no metadata field.
