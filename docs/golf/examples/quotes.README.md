# Golf quotes example

`quotes.txt` is generated by `scripts/scrape_golf_quotes.py` from English
Wikiquote. Wikiquote text is available under the
[CC BY-SA 4.0 licence](https://creativecommons.org/licenses/by-sa/4.0/).

Regeneration is a manual development step. To use the generated collection,
copy `quotes.txt` to the SD card as `/golf/quotes.txt`.

Quotes from documented golfers are collected from their subject pages. Quotes
from the Golf theme page and general figures are retained only when the quote
text contains an explicit golf term; ambiguous terms need additional golf
context on general-figure pages. Bibliography/index-like entries are discarded,
and missing golfer pages are retried with ASCII and golfer-title variants where
appropriate.
