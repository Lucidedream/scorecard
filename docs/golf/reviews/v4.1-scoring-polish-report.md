## Header source and containment

The original emphasis came from the shared header path:

- `src/components/themes/BaseTheme.cpp:327` copied `tokens.titleText` into the header title; `freeink-sdk/libs/ui/FreeInkUI/src/FreeInkUI.cpp:97` makes that token bold.
- `src/components/themes/BaseTheme.cpp:330` copied `tokens.popup`; the FreeInkUI header component fills that style's background.
- Because `BaseTheme::drawHeader()` is also used by non-golf activities, changing it would have restyled reader/settings screens and created a sixteenth upstream touchpoint.

The golf-owned implementation is now `golfui::drawHeader()` in `src/activities/golf/GolfUiLayout.cpp:49`. It reuses the active theme's font geometry, title alignment, battery metrics, battery component, percentage setting, and right-label placement, but forces the title to regular/non-inverted text (`:90-93`), does not paint a band background, and retains a bottom rule (`:107-110`). It uses the existing shared static theme-token pool by reference, performs no heap allocation, and adds no persistent DRAM.

## Counter digits

`src/activities/golf/GolfUiLayout.h:111-115` keeps 100 px focused and 66 px unfocused as the preferred heights. The overflow ceiling is `rowHeight - 24`, exactly reserving the 12 px downward nudge on both sides of the vertical center; `GolfScoringActivity.cpp:606-608` applies that nudge.

At an 800 px portrait height, 15 px top padding, and a 24 px host-test font minimum:

| Penalty band | Focused row / digit | Unfocused rows / digits |
| --- | --- | --- |
| Present | 175 px / **100 px** | 123 px / **66 px** |
| Absent | 193 px / **100 px** | 132 and 133 px / **66 px** |

Thus the clamp is inactive for all focused and unfocused rows in both requested 800 px cases. Existing test `GolfUiLayout.LyraHeaderRecoveryIsRedistributedToWeightedScoringBands` now asserts these values plus the short-row guard boundary (`123 -> 99` focused and `89 -> 65` unfocused).
